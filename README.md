# 快乐二级域名分发系统 （kldns-pro v3.1.1）

## 此系统有哪些特点
* 目前支持的域名解析平台有
    *  dnspod
    *  cloudxns
    *  aliyun
    *  dnscom
    *  dnsla
    *  cloudflare
    *  DnsDun
* 多用户、多域名、多平台同时存在
* 界面简单、舒适，操作简单

## 安装说明
* 1、程序的框架是Laravel 5.8，因此需要环境满足以下要求：
    * PHP >= 7.1.3 且 < 8.0
* 2、环境必须支持伪静态

* Apache 伪静态配置
    * 确保 Apache 启用了 mod_rewrite 模块以支持 .htaccess 解析。
* Nginx 伪静态配置

        location / {
            try_files $uri $uri/ /index.php?$query_string;
        }

## 有问题反馈
如果您在使用过程中遇到任何问题，欢迎反馈。为了能够更快速有效地解决问题，请提供以下信息：

### 提交问题时需要提供的信息
1. **系统环境**：
   - PHP版本
   - 数据库类型和版本
   - Web服务器类型和版本（Apache/Nginx）
   - 操作系统信息

2. **问题描述**：
   - 详细描述您遇到的问题
   - 问题发生的具体步骤
   - 预期的结果与实际结果的差异
   - 相关的错误信息或日志（如有）

3. **截图或录屏**：
   - 如可能，提供问题发生时的界面截图
   - 对于复杂操作流程，可提供简短录屏

4. **复现步骤**：
   - 详细的操作步骤，以便我们能够在测试环境中复现问题

5. **日志信息**：
   - **重要**: 提交日志前请先清空日志文件
   - 清空日志文件方法: 删除storage/logs/里面的.log文件
   - 然后重新复现问题
   - 复制新产生的日志内容提交

### 问题反馈渠道

### 常见问题解决方法
1. **安装问题**：
   - 确保您的环境满足上述所有要求
   - 检查文件权限，确保存储和缓存目录可写
   - 查看日志文件（`storage/logs/laravel.log`）获取详细错误信息

2. **DNS解析问题**：
   - 确认API密钥和账号信息正确
   - 检查域名是否已在对应平台添加并授权
   - 查看系统日志了解具体错误原因

3. **升级问题**：
   - 升级前请务必备份数据库和全部文件
   - **本系统所有数据都存储在数据库中，升级只需要替换项目文件即可**
   - 升级步骤：
     1. 备份数据库
     2. 备份原项目文件（以防万一）
     3. 替换所有项目文件（保留 `.env` 文件不变）
     4. 替换文件（如果你的项目文件没有进行其他更改的话，可以全部替换）
     5. 查看功能是否全部正常，数据是否有问题！！！
